## ¿Por qué Linux?

Aunque en escritorio sea minoritario, Linux es el sistema operativo más usado del planeta:

- Las 500 supercomputadoras más potentes del mundo corren Linux (el 100% desde 2017).
- Alrededor del 90% de la infraestructura de nube pública corre Linux: 92% de las VMs de Google Cloud, 84% de las instancias EC2 de AWS y 62% de las VMs de Azure.
- Android está construido sobre el kernel de Linux, así que lo lleva encima más del 70% de los celulares del mundo.
- El 92% de los servidores con sistema operativo conocido son Unix-like.
- Solo en 2025, más de 5.200 desarrolladores de más de 1.780 organizaciones contribuyeron al kernel.
- En escritorio ronda el 4,5% a nivel global, pero ya supera el 10% en Estados Unidos y viene subiendo rápido.
- También corre en los vehículos autónomos y en Chrome OS.

### Algunos usos curiosos

- **Steam Deck**: Valve metió Linux (SteamOS) adentro de una consola portátil.
- **Ingenuity**: el helicóptero de la NASA que voló en Marte llevaba Linux a bordo.
- **Red Star OS**: Corea del Norte tiene su propia distribución.
- **PewDiePie**: el youtuber más conocido de la última década se pasó a Linux.

### ¿Por qué le dedicamos tiempo de clase?

- Para poder seguir la cursada vas a necesitar Linux o macOS.
- Lo vas a volver a necesitar a lo largo de toda la carrera.
- Es más rápido, más simple y más robusto para desarrollar.
- Te va a dar una vida profesional más cómoda y competitiva.


## Opciones de instalación
Empezar a usar Linux puede parecer un poco complicado e intimidante al principio, pero hay varias opciones de instalación según lo que necesites y el uso que le vayas a dar. Ya sea que quieras tener Linux junto con otro sistema en la misma máquina, probarlo en una máquina virtual sin tocar nada de tu sistema actual, o probar con contenedores, te contamos cómo hacerlo de la forma más fácil.

:::tip Recomendación de la cátedra
Si podés, **instalá Linux de forma nativa** (dual-boot o reemplazando el sistema): es la opción más performante y con la que vas a estar más cómodo. Si estás en Windows y no querés tocar el disco, **WSL2** es una alternativa aceptable. La **máquina virtual** funciona, pero es la menos recomendada. Y si tenés **macOS**, podés seguir las clases sin instalar nada.
:::

1. ## Instalación Dual-Boot
    La instalación dual-boot te permite tener dos sistemas operativos en la misma máquina. Así, podés elegir cuál usar al arrancar el equipo.
   ### Pasos para la Instalación Dual-Boot:
   1. **Preparación**:

   - **Respaldo de Datos**: Hacete un backup de toda tu data importante antes de empezar, no vaya a ser cosa que pase algo raro.
   - **Espacio en Disco**: Asegurate de tener espacio libre en el disco. Podés usar herramientas como _GParted_ para redimensionar particiones si es necesario.
   2. **Crear una Partición para Linux:**
    - Usá una herramienta de particionamiento para hacer una nueva partición para Linux. Asegurate de dejar espacio suficiente para la instalación.
   3. **Arrancar desde el Medio de Instalación:**
    - Usá un DVD, CD o USB booteable con la imagen de Linux para arrancar el proceso de instalación.
   4. **Instalar Linux:** 
    - Durante la instalación, elegí la opción de instalar Linux junto con el sistema operativo que ya tenés. El instalador debería detectar tu sistema actual y configurar el gestor de arranque (como GRUB) para que puedas elegir entre ambos sistemas cuando inicies la PC.
   5. **Completar la Instalación:**
      - Seguí las instrucciones del instalador y, al reiniciar, vas a poder elegir entre Linux y tu sistema operativo original en el menú de arranque.
2. ## Windows Subsystem for Linux (WSL2)
    WSL2 te permite correr una distribución de Linux dentro de Windows, con un kernel real de Linux, sin reiniciar ni particionar el disco. Es bastante más performante que una máquina virtual y te deja abrir una terminal de Linux como si fuera una aplicación más. Requiere Windows 11 o una versión actualizada de Windows 10.
   ### Pasos para instalar WSL2:
   1. **Abrir PowerShell como administrador**:
    - Clic derecho en el menú de inicio y elegí *Terminal (Administrador)*.
   2. **Instalar WSL:**
    - Ejecutá `wsl --install`. Por defecto instala Ubuntu.
    - Si querés otra distribución, `wsl --list --online` te muestra las disponibles y `wsl --install -d <nombre>` instala la que elijas.
   3. **Reiniciar la computadora:**
    - Reiniciá cuando el instalador te lo pida.
   4. **Crear tu usuario:**
    - La primera vez que abras la distro te va a pedir un nombre de usuario y una contraseña de Linux, independientes de los de Windows.
   5. **Actualizar los paquetes:**
    - Corré `sudo apt update && sudo apt upgrade` para dejar el sistema al día.

    **A favor**: instalación simple, poco invasiva, mucho más rápida que una VM y podés correr Docker sin problemas.
    **En contra**: es exigente con el hardware, necesitás una versión reciente de Windows y seguís trabajando dentro de Windows.

3. ## Instalación en una Máquina Virtual
    Instalar Linux en una máquina virtual te permite usar el sistema operativo en un entorno virtualizado dentro de tu sistema operativo principal. Ideal para probar o desarrollar sin tocar tu sistema principal.
    ### a. Usando VirtualBox:
      1. **Descargar e Instalar VirtualBox**:
          - Bajate VirtualBox desde su sitio oficial e instalalo en tu máquina.
      2. **Crear una Nueva Máquina Virtual:**
      	 - Abri VirtualBox y crea una nueva máquina virtual. Asigná memoria (RAM) y espacio en disco según las recomendaciones de la distribución de Linux que quieras instalar.
      3. **Montar la Imagen ISO:**
         -  En la configuración de la máquina virtual, montá la imagen ISO de Linux como unidad de CD/DVD.
      4. **Iniciar la Instalación:**
         - Iniciá la máquina virtual. El instalador de Linux debería arrancar desde la imagen ISO. Seguí las instrucciones para instalar Linux en la máquina virtual.
      5. **Configuración Posterior:**
           - Una vez instalado, podés ajustar la configuración de la máquina virtual según lo necesites.

    ### b. Usando VMware:
      1. **Descargar e Instalar VMware Workstation Player:**
          - Bajate VMware Workstation Player desde su sitio oficial e instalalo en tu PC.
      2. **Crear una Nueva Máquina Virtual:**
      	 - Abri VMware y crea una nueva máquina virtual, asignando recursos como memoria y espacio en disco.
      3. **Montar la Imagen ISO:**
         -  Configurá la máquina virtual para usar la imagen ISO de Linux.
      4. **Iniciar la Instalación:**
         - Iniciá la máquina virtual y seguí las instrucciones del instalador de Linux.
4. ## Instalación en un Entorno de Contenedores
Los contenedores, como los que ofrece Docker, te permiten ejecutar aplicaciones y entornos aislados dentro del mismo sistema operativo sin necesidad de instalar un SO completo.
####  Uso Básico de Docker:
   1. **Instalar Docker:**
         - Bajate e instalá Docker Desktop desde el sitio oficial para tu sistema operativo.
   2. **Descargar una imagen de Linux:**
      	 - Usá Docker para bajar una imagen de una distribución de Linux. Por ejemplo, podés usar el comando 	***docker pull ubuntu*** para obtener una imagen de Ubuntu.
.
   3. **Ejecutar un Contenedor:**
         -  Creá y ejecutá un contenedor con la imagen descargada. Por ejemplo: ***docker run -it ubuntu***.
   4. **Trabajar dentro del Contenedor:**
         - Podés ejecutar comandos dentro del contenedor y configurar el entorno según lo necesites.

#### Consideraciones Finales
- **Compatibilidad:** Verificá que el hardware y el software que usás sean compatibles con el método de instalación que elegiste.
- **Respaldo y Seguridad:** No te olvides de realizar copias de seguridad antes de modificar particiones o instalar nuevos sistemas operativos.

## Descubriendo Linux

Linux, un nombre que a menudo se usa para describir un sistema operativo completo, en realidad se refiere al kernel del sistema, el núcleo que gestiona la comunicación entre el hardware y el software. Aunque el kernel de Linux es fundamental para el funcionamiento del sistema, no es suficiente por sí solo para constituir un sistema operativo completo. Para formar un sistema operativo funcional, Linux debe integrarse con una variedad de componentes adicionales, incluyendo bibliotecas, herramientas y utilidades que proporcionan una interfaz completa para el usuario y gestionan diversas tareas del sistema.

En su esencia, Linux es un sistema operativo *Unix-like*, lo que significa que comparte características y conceptos fundamentales con los sistemas operativos basados en Unix. Esta herencia Unix proporciona a Linux una estructura robusta y flexible, con una fuerte orientación hacia la multitarea, la seguridad y la estabilidad. La similitud con Unix también se refleja en la interfaz de línea de comandos y en las herramientas estándar que permiten a los usuarios y administradores gestionar el sistema de manera eficiente.

### ¿Qué es un sistema operativo?

Es el software que gestiona los recursos de la computadora: reparte la CPU entre los procesos, administra la memoria y el disco, habla con el hardware (placa de video, wifi, teclado) y te da una interfaz para usar todo eso. Windows, macOS, Android y Ubuntu son sistemas operativos.

### ¿Y el kernel?

El kernel es el **núcleo** del sistema operativo: la única parte que le habla directo al hardware. Si pensamos el sistema como capas, queda algo así:

| Capa | Ejemplos |
| --- | --- |
| Tus programas | Chrome, VS Code, la terminal |
| Librerías y herramientas del sistema | GNU coreutils, bash, gcc |
| **Kernel** | procesos, memoria, drivers, sistema de archivos |
| Hardware | CPU, RAM, disco, placa de red |

Linux es solamente esa capa: por sí solo no te da ni una terminal. Kernel + herramientas + interfaz es lo que forma un sistema operativo usable, y por eso se suele hablar de **GNU/Linux**: el kernel lo puso Linux y buena parte de las herramientas las puso el proyecto GNU.

### Las distribuciones ("distros")

Una **distribución** es un sistema operativo armado sobre el kernel de Linux: el kernel más un gestor de paquetes, un entorno de escritorio y un conjunto de programas preinstalados. Cada una tiene su propio enfoque y filosofía, y son las que realmente se instalan. Las más conocidas se agrupan en familias:

- **Debian**: Debian, Ubuntu, Linux Mint, Pop!\_OS, Kali. Usan `apt` y son las más recomendadas para arrancar.
- **Red Hat**: Fedora, RHEL, CentOS, Rocky. Usan `dnf` o `yum`.
- **Arch**: Arch Linux, Manjaro, EndeavourOS. Usan `pacman`.
- **Otras**: openSUSE, Gentoo, Alpine (muy usada en contenedores), NixOS.

Si es tu primera vez, **Ubuntu** o **Linux Mint** son las apuestas más seguras.

### Un poco de historia

**UNIX (1969)**. Desarrollado en los Bell Labs de AT&T por Ken Thompson y Dennis Ritchie, inspirado en el proyecto Multics. El lenguaje C fue creado justamente para implementarlo. Definió el universo de lo que hoy llamamos sistemas *Unix-like*.

**GNU (1983)**. Richard Stallman arranca el GNU Project, cuyo nombre es un acrónimo recursivo (**G**NU's **N**ot **U**nix). Introduce el concepto de *copyleft* y la GNU General Public License (GPL). Uno de sus objetivos era construir un Unix-like libre y llegó a implementar herramientas como GCC, GNU Emacs, GIMP, Bash y GDB, pero nunca terminó su propio kernel.

**Linux (1991)**. Proyecto personal del finlandés Linus Torvalds. Ya había sistemas Unix-like dando vueltas, pero ninguno libre y compatible con los procesadores Intel 386. Torvalds lo licencia bajo la GPL y, combinado con los componentes de GNU, queda por fin un sistema operativo completo y libre.


## ¿Qué es un sistema operativo “UNIX-LIKE”?

Un sistema operativo *Unix-like* es un tipo de software que funciona de manera parecida a Unix, un sistema operativo muy antiguo y famoso. Aunque estos sistemas no tienen que ser idénticos a Unix, siguen algunas de sus ideas y características principales tales como:

- **Estructura de archivos**: Organizan los archivos en una **forma jerárquica**, parecida a un árbol, comenzando desde un directorio raíz (/) y dividiéndose en carpetas y subcarpetas. El directorio raíz (o root directory) contiene archivos y subdirectorios que contienen más archivos y subdirectorios y así sucesivamente. A diferencia de Windows, Linux tiene un único árbol con los archivos del sistema sin importar cuántos dispositivos de almacenamiento estén conectados a la computadora.

  **Para navegar en esta estructura, se utilizan dos tipos de rutas:**

- **Rutas Absolutas (Absolute Pathnames)**: Estas rutas comienzan desde el directorio raíz (/) y siguen la jerarquía del sistema de archivos hasta llegar

  al archivo o directorio deseado. Una ruta absoluta siempre inicia en el directorio raíz, proporcionando una ubicación completa en el sistema.

- **Rutas Relativas (Relative Pathnames)**: Estas rutas comienzan desde el directorio de trabajo actual en lugar del directorio raíz. Utilizan símbolos especiales para representar posiciones relativas en el sistema de archivos. El símbolo “.” representa el directorio de trabajo actual, mientras que “..” representa el directorio padre o el directorio anterior.

![foto arbol_directorios](https://i.imgur.com/uUrIOtF.png)

*Árbol de directorios de Linux*

- **Interfaz de línea de comandos**: Permiten a los usuarios escribir comandos en lugar de solo hacer clic con el ratón. Esto puede ser muy útil para realizar tareas y controlar el sistema.
- **Multitarea y multiusuario**: Pueden manejar varias tareas al mismo tiempo y permitir que múltiples personas usen el sistema simultáneamente sin interferir entre sí.
- **Permisos y seguridad**: Controlan quién puede acceder a qué archivos y recursos del sistema, asegurando que solo las personas autorizadas puedan hacer ciertas cosas.
- **POSIX**: Muchos sistemas *Unix-like* siguen un estándar llamado POSIX, que significa **Portable Operating System Interface** (Interfaz de Sistema Operativo Portátil). Este estándar define reglas y especificaciones sobre cómo deben comportarse los sistemas operativos para garantizar la compatibilidad entre ellos. En otras palabras, POSIX asegura que los programas escritos para un sistema *Unix-like* puedan ejecutarse también en otros sistemas similares que cumplan con este estándar.

**Ejemplos de sistemas *Unix-like*** incluyen Linux, macOS y BSD (que incluye varios sistemas derivados como FreeBSD).

## La línea de comandos y el shell

Cuando hablamos de la línea de comandos en un sistema operativo, nos referimos a una herramienta que te permite interactuar con el sistema mediante texto en lugar de gráficos. Esta herramienta es conocida como **shell**.

#### ¿Qué es?

Es un programa que actúa como intermediario entre quien usa la línea de comandos y el sistema operativo. Su función principal es tomar los comandos que escribe el usuario y traducirlos en acciones que el sistema operativo puede ejecutar. En otras palabras, cuando escribís un comando en el shell y presionas "Enter", el shell toma ese comando, lo envía al sistema operativo, y después te muestra el resultado en la pantalla.

#### ¿Cómo funciona?

1. **Ingresamos un comando**: Abrimos el shell e ingresamos un comando, como **ls** para listar archivos en una carpeta.
1. **El shell lo procesa**: El shell toma ese comando y lo envía al sistema operativo.
1. **El sistema operativo ejecuta el comando**: El sistema operativo realiza la acción solicitada, como mostrar los archivos.
1. **El shell muestra el resultado**: El shell muestra el resultado en la pantalla, como la lista de archivos.

En la mayoría de las distribuciones de Linux, el shell que se utiliza por defecto es **bash**, que significa **Bourne Again Shell**. Este nombre hace referencia a **sh** (Bourne Shell), un shell más antiguo.

## Emuladores de terminal

Cuando usamos una interfaz gráfica de usuario (GUI), solemos necesitamos un emulador de terminal para interactuar con el sistema operativo a través del shell. El emulador de terminal es una aplicación que nos permite escribir comandos y ejecutar programas en modo texto, similar a cómo se haría en una consola de *texto puro*.

### **Shell Prompt**

- **\[username@machinename~\]$**: Este es el **prompt** del shell. `username` es tu nombre de usuario, `machinename` es el nombre de tu computadora, y el símbolo `$` te dice que estás trabajando como usuario normal. Si en vez de `$` ves un `#`, significa que estás trabajando como **root** o superusuario, que tiene todos los permisos para hacer cambios importantes en el sistema.

### **Uso básico de la terminal**

- **Historial de comandos**: Si querés ver los comandos que usaste antes, podés usar la flecha hacia arriba en tu teclado. Esto te permite recorrer el historial de comandos que escribiste.
- **Mover el cursor**: Usá las flechas izquierda (←) y derecha (→) para mover el cursor dentro de la línea de texto. Así podés corregir o modificar lo que estás escribiendo.
- **Modificar o “agregar” funciones al comando que estamos utilizando:** Las flags son opciones adicionales que puedes agregar a un comando para modificar su comportamiento o salida. Estas se especifican usando un guión (-) o doble guión (--) seguido de una letra o palabra clave.
- **Copiar y pegar**:
- **Copiar**: Para copiar texto, seleccionás lo que querés con un doble clic o simplemente “pintando” lo que querés copiar con el cursor.
- **Pegar**: Para pegar lo que copiaste, se puede utilizar el botón de la rueda del mouse (o el clic central, dependiendo del sistema) o ctrl+shift+v.

Mencionamos en la explicación anterior un concepto muy interesante, ***texto puro***. ¿Pero qué es?

Es un formato básico de datos que se compone únicamente de caracteres, sin ningún tipo de formato adicional. A diferencia de los archivos creados en procesadores de texto como Microsoft Word, que pueden incluir estilos, colores, fuentes y otros elementos de formato, el texto puro es simplemente una **secuencia de caracteres representada por números**.

##### **¿Cómo funciona el Texto Puro?**

- **Asignación directa**: En el texto puro, cada carácter se asigna directamente a un número a través de una codificación estándar (como ASCII o UTF-8). Por ejemplo, la letra "A" tiene un valor numérico específico en estas codificaciones.
- **Tamaño de archivo**: Si tienes 50 caracteres en un archivo de texto puro, esos 50 caracteres se traducen a 50 bytes de datos. Es decir, cada carácter ocupa exactamente un byte en el archivo, sin contar con ningún formato adicional.

##### **Importancia del texto puro**

1. **Archivos de configuración**: Muchos archivos que configuran el sistema y las aplicaciones están en formato de texto puro. Estos archivos, como config.txt o /etc/fstab, contienen ajustes esenciales que el sistema necesita para funcionar correctamente.
1. **Scripts y programas**: Muchos scripts y programas en Linux y otros sistemas operativos están escritos en texto puro. Esto incluye scripts de shell, scripts de Python, y otros programas que se ejecutan en el sistema. El texto puro permite que estos scripts sean fácilmente leídos y editados.
3. **Facilidad de lectura**: Al ser un formato simple, el texto puro es fácil de leer y editar usando cualquier editor de texto básico. Esto lo hace ideal para ver y modificar configuraciones y scripts sin necesidad de herramientas especializadas.

## Comandos más usados en Linux

Para facilitar el manejo del sistema y mejorar la eficiencia en la administración, es esencial familiarizarse con los comandos básicos que se utilizan en la terminal. En la siguiente lista, vas a encontrar comandos básicos junto con sus usos y opciones adicionales (flags) que amplían su funcionalidad.

**ls**

- **Uso**: Lista el contenido de un directorio.
- **Flags útiles**:
- -l: Muestra detalles extensos como permisos, tamaño y fecha de los archivos.
- -a: Muestra los archivos ocultos (los que empiezan con un punto .).
- -h: Muestra tamaños en un formato legible (ej. KB, MB).

**alias**

- **Uso**: Define o muestra alias para comandos, que son atajos para comandos más largos.
- **Ejemplo**: alias ll='ls -l' define ll como un alias para ls -l.

**unalias**

- **Uso**: Elimina los alias que hayas definido.
- **Ejemplo**: unalias ll elimina el alias ll.

**pwd**

- **Uso**: Muestra el directorio de trabajo actual (Print Working Directory).

**cd**

- **Uso**: Cambia al directorio especificado. (Change Directory)
- **Ejemplo**: cd /home/usuario/ te lleva al directorio /home/usuario/.

**cp**

- **Uso**: Copia archivos y directorios.
- **Flags útiles**:
- -r: Copia directorios de forma recursiva.
- -i: Te pregunta antes de sobrescribir archivos.

**rm**

- **Uso**: Borra archivos y directorios.
- **Flags útiles**:
- -r: Borra directorios y su contenido de forma recursiva.
- -f: Fuerza la eliminación sin pedir confirmación.

**mv**

- **Uso**: Mueve o renombra archivos y directorios.
- **Flags útiles**:
- -i: Pregunta antes de sobrescribir archivos.

**mkdir**

- **Uso**: Crea nuevos directorios (carpetas).
- **Flags útiles**:
- -p: Crea directorios padres si es necesario.

**man**

- **Uso**: Muestra la página del manual para otros comandos.
- **Ejemplo**: man ls te da la documentación para el comando ls.

**touch**

- **Uso**: Crea archivos vacíos o actualiza la fecha de modificación de archivos existentes.

**chmod**

- **Uso**: Cambia los permisos de archivos y directorios.
- **Ejemplo**: chmod 755 archivo establece permisos de lectura, escritura y ejecución para el propietario, y solo lectura y ejecución para otros.

**./**

- **Uso**: Ejecuta un archivo ejecutable en el directorio actual.
- **Ejemplo**: ./script.sh corre el script script.sh.

**exit**

- **Uso**: Sale de la sesión actual del shell.

**sudo**

- **Uso**: Ejecuta comandos con permisos de superusuario o administrador.
- **Ejemplo**: sudo apt update actualiza los paquetes del sistema con permisos elevados.

**shutdown**

- **Uso**: Apaga o reinicia la computadora.
- **Flags útiles**:
- -h: Apaga la computadora.
- -r: Reinicia la computadora.

**htop**

- **Uso**: Muestra información interactiva sobre los procesos y los recursos del sistema.

**unzip**

- **Uso**: Extrae archivos de un archivo ZIP comprimido.
- **Flags útiles**:
- -d: Especifica el directorio donde se extraerán los archivos.

**apt, yum, pacman**

- **Uso**: Gestores de paquetes para instalar, actualizar y eliminar software.
- **Ejemplos**:
- apt-get install paquete: En sistemas basados en Debian.
- yum install paquete: En sistemas basados en Red Hat.
- pacman -S paquete: En Arch Linux.

**echo**

- **Uso**: Muestra texto o variables en la terminal.
- **Ejemplo**: echo "Hola Mundo" imprime "Hola Mundo" en la terminal.

**cat**

- **Uso**: Muestra el contenido de un archivo.
- **Flags útiles**:
- -n: Numera las líneas de la salida.

**Bat**

- **Uso:** Nos va a mostrar el contenido de un archivo, justo como cat, pero con la sintaxis resaltada para la mayoría de los lenguajes de programación
- -a: Puede resaltar los tabuladores, los espacios y los saltos de línea.

**ps**

- **Uso**: Muestra información sobre los procesos en ejecución.
- **Flags útiles**:
- -e: Muestra todos los procesos.
- -f: Muestra información detallada sobre los procesos.

**kill**

- **Uso**: Termina procesos.
- **Flags útiles**:
- -9: Fuerza la terminación inmediata del proceso.

**ping**

- **Uso**: Verifica la conectividad de red con otro host.
- **Flags útiles**:
- -c: Especifica el número de paquetes a enviar.

**vim**

- **Uso**: Editor de texto avanzado y eficiente para editar archivos.

**history**

- **Uso**: Muestra una lista de los comandos que has usado recientemente.

**passwd**

- **Uso**: Cambia la contraseña del usuario actual.

**which**

- **Uso**: Muestra la ruta completa del ejecutable de un programa.
- **Ejemplo**: which python muestra la ubicación del ejecutable de Python.

**shred**

- **Uso**: Sobrescribe un archivo para ocultar su contenido y hacerlo más difícil de recuperar.
- **Flags útiles**:
- -u: Elimina el archivo después de sobreescribirlo.

**less**

- **Uso**: Permite inspeccionar archivos de manera interactiva, desplazándote hacia adelante y hacia atrás.
- **Flags útiles**:
- -h: Muestra tamaños de archivo en formato legible para humanos.

**tail**

- **Uso**: Muestra las últimas líneas de un archivo.
- **Flags útiles**:
- -f: Muestra en tiempo real las nuevas líneas añadidas al archivo.

**head**

- **Uso**: Muestra las primeras líneas de un archivo.
- **Flags útiles**:
- -n: Especifica el número de líneas a mostrar.

**grep**

- **Uso**: Busca y muestra líneas que coinciden con un patrón de texto.
- **Flags útiles**:
- -i: Ignora mayúsculas y minúsculas durante la búsqueda.
- -r: Realiza la búsqueda de manera recursiva en directorios.

**whoami**

- **Uso**: Muestra el nombre del usuario actual.

**whatis**

- **Uso**: Proporciona una breve descripción del comando.
- **Ejemplo**: whatis ls muestra una breve descripción del comando ls.

**wc**

- **Uso**: Cuenta palabras, líneas y caracteres en archivos.
- **Flags útiles**:
- -l: Cuenta solo las líneas.
- -w: Cuenta sólo las palabras.

**uname**

- **Uso**: Muestra información sobre el sistema operativo.
- **Flags útiles**:
- -a: Muestra toda la información disponible sobre el sistema.

**neofetch**

- **Uso**: Muestra una vista estilizada de la información del sistema operativo y del hardware.

**find**

- **Uso**: Busca archivos y directorios que coincidan con un patrón.
- **Flags útiles**:
- -name: Busca por nombre de archivo.
- -type: Busca por tipo de archivo (por ejemplo, f para archivos regulares).

**wget**

- **Uso**: Descarga archivos desde Internet.
- **Flags útiles**:
- -O: Especifica el nombre del archivo de salida.
- -r: Descarga de forma recursiva desde un directorio web.
